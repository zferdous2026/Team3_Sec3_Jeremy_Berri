#Data Description and Metadata
The Olympic Athletes and Medals dataset is a collection of information
about athletes who participated in the modern Olympic Games between 1896 and 2016
It includes both Summer and Winter Olympics and provides information about
athletes' personal characteristics, the countries they represented, the sports
and events they competed in, and whether they earned medals.The original data
comes from the Kaggle collection 120 Years of Olympic History: Athletes and
Results, compiled by RGriffin using historical Olympic records. 

#Column Description 
The file athlete_events.csv contains 271116 rows and 15 columns. 
Each row corresponds to an individual athlete competing in an individual 
Olympic event (athlete-events). The columns are:

ID - Unique number for each athlete
Name - Athlete's name
Sex - M or F
Age - Integer
Height - In centimeters
Weight - In kilograms
Team - Team name
NOC - National Olympic Committee 3-letter code
Games - Year and season
Year - Integer
Season - Summer or Winter
City - Host city
Sport - Sport
Event - Event
Medal - Gold, Silver, Bronze, or NA

#Our App
Our app is an interactive Olympic data dashboard that allows users to
explore Olympic history. Users can filter information by
country, year, sport, gender, and medal type to discover trends in Olympic
participation and performance, as these are the columns we used. The app
features interactive graphs, charts,
and statistics showing medal counts, athlete demographics, and how the Olympics
have changed over time. The goal is to make Olympic data easy to explore,
compare, and understand through engaging visualizations.
